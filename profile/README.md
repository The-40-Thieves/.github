# The 40 Thieves. Tools first.

Open-source developer tools, each with one measured claim and a one-line install.

| Project                                                    | What it is                                                                                                          | Install                                 |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| [codecalc](https://the40thieves.dev/codecalc/)             | A calculator, a code runner and a logic checker for AI agents: 51 MCP tools across 31 languages, sandboxed in Rust. | `uvx 'codecalc[full]' setup --write`    |
| [alexandria-mcp](https://the40thieves.dev/alexandria-mcp/) | Search, read and cite across 152 public digital libraries from any MCP client.                                      | `npx -y @the-40-thieves/alexandria-mcp` |
| [audio-forge](https://the40thieves.dev/audio-forge/)       | An audio delivery pipeline AI agents can drive: a track and a target in, a spec-compliant master out.               | build from source, see the project page |

Everything here is Apache-2.0. Product pages, install snippets for each client, the release feed and a machine-readable manifest live at [the40thieves.dev](https://the40thieves.dev).
